# INSTALLATION

Chrome/Edge:

Go to chrome://extensions or edge://extensions

Enable Developer Mode
Click Load unpacked
SelEct folder

Firefox:
Go to about:debugging
Click This Firefox
Click Load Temporary Add-on
Select manifest.json
Click extension icon
Enter target URL
Set intensity
Click START
Click STOP to end
